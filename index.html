⚙️ Instructions pour Windows

  1. Branchez l'imprimante Epson en USB
  2. Téléchargez le driver sur epson.com
  3. Allez dans Paramètres → Périphériques → Imprimantes
  4. Définissez Epson TM-T20III comme imprimante par défaut
  5. Désactivez "Aperçu avant impression"
  6. Dans Chrome, allez dans Paramètres → Impression → Destination → Enregistrer comme imprimante par défaut
